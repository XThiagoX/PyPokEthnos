# PyPokEthnos

Implementação em Python do jogo de tabuleiro Ethnos com temática Pokémon. Projeto desenvolvido para a disciplina de Gerência de Projetos e Manutenção de Software (GPMS) na UFF.

## Como rodar

1. Clone o repositório
2. Crie um ambiente virtual: `python -m venv venv`
3. Ative-o: `source venv/bin/activate` (Linux/macOS)
4. Execute: `python src\main.py`
